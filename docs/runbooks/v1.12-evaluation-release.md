# V1.12 评估发布运行手册

1. Complete and review the `pilot` and `wave` curation work; only the final
   `release` profile may proceed.
2. Start the isolated PostgreSQL Compose project and migrate it.
3. Place licensed official material under `data/benchmarks/sha256/{prefix}/{sha256}`.
4. Run `benchmark source-status`, `benchmark preflight --profile release`, then
   `benchmark ingest-manifest --file <manifest.json>`.
5. Import and obtain two-person approval for a sealed blind label pack.
6. Run `python -m app.manage benchmark verify`.
7. Run `python -m app.manage evaluation run-release --provider mock --label-pack <id> --wait`.
8. Run `python -m app.manage evaluation verify` and inspect every failed verification and critical Review Case.
9. Create the release checkpoint and `v1.12.0-rc1` tag only after exactly
   84 Engineering + 330 Historical members and all fail-closed gates pass.

Never expose the blind decryption key to the API image used for ordinary operation. It is only supplied to the isolated release evaluator.
