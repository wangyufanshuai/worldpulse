# V1.12 评估发布运行手册

1. Start the isolated PostgreSQL Compose project and migrate it.
2. Place licensed official material under `data/benchmarks/sha256/{prefix}/{sha256}`.
3. Run `python -m app.manage benchmark ingest-manifest --file <manifest.json>`.
4. Import and obtain two-person approval for a sealed blind label pack.
5. Run `python -m app.manage benchmark verify`.
6. Run `python -m app.manage evaluation run-release --provider mock --label-pack <id> --wait`.
7. Run `python -m app.manage evaluation verify` and inspect every failed verification and critical Review Case.

Never expose the blind decryption key to the API image used for ordinary operation. It is only supplied to the isolated release evaluator.
