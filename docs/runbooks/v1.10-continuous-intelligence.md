# V1.10 持续情报运行手册

## 启用

持续情报默认关闭。配置 API 与 ingestion worker 使用相同数据库和上传卷，并为两个进程设置：

```text
WORLDPULSE_CONTINUOUS_INTELLIGENCE=1
WORLDPULSE_FEED_ALLOW_HTTP=0
WORLDPULSE_WEBHOOK_HOST_ALLOWLIST=hooks.example.org
WORLDPULSE_WEBHOOK_SECRET_PRIMARY=<random-secret>
```

生产环境不要开启 HTTP。Webhook 订阅中的 `secret_ref=PRIMARY` 对应上面的环境变量后缀；数据库只保存引用。

## 日常检查

```text
python -m app.manage migrate verify
python -m app.manage blobs verify
python -m app.manage monitoring verify
python -m app.manage monitoring poll-due
python -m app.manage notifications retry-failed
```

`monitoring verify` 检查 schema、告警 lineage 与队列摘要。Operations Center 展示待处理 Poll、降级 Source、开放告警和 Webhook 积压。功能启用时应始终运行 ingestion worker。

## 故障处理

- Source 连续失败：确认 DNS、证书、MIME、响应大小和发布时间；不要绕过 SSRF 门禁。修复后恢复 Source 或手动 Poll。
- Candidate 未出现：检查 Alert lineage、Document、Extraction Job 与 `candidate.ready` 事件。后台路径强制使用确定性抽取。
- Webhook 失败：确认目标在 allowlist、secret 环境变量存在且目标返回 2xx；随后运行 retry 命令。
- Blob/Hash 错误：停止相关材料处理，执行 blob verify，并从数据库与 `data/uploads` 的同一备份点恢复。

暂停或退休 Source 不删除已完成材料、候选和告警历史。任何内容 revision 都追加记录，不能覆盖旧 revision。
