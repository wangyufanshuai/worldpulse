# V1.8 多轮外交博弈运行手册

1. 执行 `python -m app.manage migrate`，确认 `0006_v18_negotiation` 已应用。
2. 启动 API 与独立 lifecycle worker。
3. 默认保持 `AGENT_PROVIDER=mock`；需要真实 Provider 时配置 allowlist Provider 的 API Key，并明确选择 `AGENT_FALLBACK_MODE=mock|skip`。
4. 在 War Room 设置中选择“多轮外交博弈”，创建运行后进入“外交博弈”模块观察 Tick、消息和承诺。
5. 故障恢复沿用 lifecycle worker：暂停/取消在 Tick 边界生效；重启 Worker 后只补齐缺失 Agent。

完整性异常必须 fail-closed。检查 `/api/v2/runs/{run_id}/audit` 和 v7 Round/消息 Hash；不要直接修改协商表。离线验证使用 `replay_negotiation_from_storage(run_id)`，该路径不得配置或调用 Provider。
