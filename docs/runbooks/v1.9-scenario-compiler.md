# V1.9 场景编译运行手册

## Enable and verify

```powershell
$env:WORLDPULSE_DOCUMENTS_ENABLED = "1"
$env:WORLDPULSE_UPLOAD_ROOT = "data/uploads"
$env:SCENARIO_EXTRACTION_PROVIDER = "disabled" # deterministic default
python -m app.manage migrate verify
python -m app.manage blobs verify
```

Production API and ingestion worker must mount the same upload volume. Backups include both the database and `data/uploads`; after restore, run `blobs verify` before enabling scenario creation. The readiness endpoint reports blob writability and queued extraction jobs.

## Governed workflow

1. Analyst/Admin uploads a UTF-8 PDF, TXT, Markdown or CSV with publisher, license, observed time and cutoff time.
2. Click **抽取**; the existing ingestion worker processes the content and emits monotonic events.
3. Analyst accepts or rejects valid candidates with page/line/row evidence locators.
4. Compile a Draft. Only preset/country/chain/policy candidates are mapped; manual numeric assumptions require a reason.
5. Submit to freeze the Evidence Pack. A different Reviewer/Admin approves, requests revision or rejects.
6. After approval, create deterministic, hybrid or negotiation run. The run and Replay Pack retain Draft/Evidence hashes.

Never place secrets, instructions, full provider responses or raw prompts in source material. A blob tamper, cutoff violation, provider strict failure or hash mismatch must remain failed/blocked until a new version is created.
