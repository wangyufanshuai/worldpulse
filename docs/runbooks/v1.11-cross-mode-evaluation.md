# V1.11 评估中心运行手册

1. `python -m app.manage migrate verify`
2. `python -m app.manage evaluation seed`
3. `python -m app.manage evaluation verify`
4. `python -m app.manage evaluation run-standard --provider mock --wait`

标准批次只允许 Mock，并生成 12 案例 × 7 个真实 v2 子运行。Live Provider 只能通过 v10 observation API 创建观察批次。安全门禁失败时保持 fail-closed，先检查 Batch Events、Artifact/Replay Hash 和 Rule Pack/Runtime Profile lineage，不要通过人工决定覆盖。
