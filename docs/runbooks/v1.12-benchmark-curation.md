# V1.12 官方历史基准整理手册

V1.12 不自动抓取网页，也不接受模型生成的历史标签。整理流程是：

1. 人工审核固定 URL、Publisher、许可证、截止时间和材料角色。
2. 使用 `benchmark validate-source-plan` 校验六领域 120 案例矩阵。
3. 使用 `benchmark fetch-sources` 通过受限 HTTPS 下载并生成 SHA-256 acquisition lock。
4. 使用 `benchmark build-manifest` 把锁定材料转换为可导入 Manifest。
5. Development 标签写入 Manifest；Blind 标签只在离线工作区生成。
6. 使用 `benchmark pack-labels` 生成 AES-256-GCM + Ed25519 密封包。
7. 由 benchmark-importer 导入，由 benchmark-reviewer 和 release-admin 分别审批。

首选许可证明确的官方数据。World Bank 数据集默认使用 CC BY 4.0，
EIA 美国政府材料通常为公共领域，FAOSTAT 数据库使用 CC BY 4.0；每个
具体数据集仍必须保存自己的许可证名称、许可证 URL 和引用格式。许可证
不允许本地归档的材料不得进入 active Suite。

盲测明文、AES 密钥和 Ed25519 私钥不得进入 Git、数据库、API 容器、
Artifact、日志或前端。标签比较开始后，标签包绑定 release root 并进入
`consuming`，正式报告生成后进入 `consumed`。
