# WorldPulse V1.11：跨模式基准评估

V1.11 对相同冻结场景分别运行 deterministic、hybrid 与 negotiation。标准套件包含六类风险、12 个工程案例和 84 个真实 v2 子运行。Mock 是唯一发布安全门禁；DeepSeek/SiliconFlow 只产生显式观察批次。

评估协调器复用现有 Run Lifecycle、War Room、Consistency、Adapter、Negotiation 和 Replay 路径。每个批次固定 Suite、Rule Pack、Runtime Profile 与 Evidence lineage Hash；成员完成后追加不可变 Metric 和事件。任何数值权威字段注入、一致性误接收、Artifact/Replay 篡改或组织作用域错误都会 fail-closed。

质量、稳定性、Token 和延迟用于分模式观察，不汇总为单一 Agent 分数，也不宣称真实世界预测准确率。
