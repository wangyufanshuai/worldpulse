# V1.2 受控 Agent Action Governance

V1.2 在 V1.1 生命周期之上增加一条可验证的 action 治理链：

```text
Agent proposal
  -> consistency audit
  -> action projection audit
  -> deterministic adapter (hybrid only)
  -> WarRoomRun / research_runs projection
```

## 权威边界

- Agent 只能提交结构化外交、舆论、联盟和解释提案。
- Agent proposal 禁止携带风险、供应链压力、全局风险或其他确定性数值权威字段。
- 一致性评估器只读检查国家能力、资源预算、目标实体、证据引用、动作方向和有效回合。
- 只有 `accepted` decision 可以进入现有 deterministic adapter；`constrained`、`rejected`、`expired` 不会直接改变确定性结果。
- 风险数值、供应链压力、时间线、因果图和最终可审计结果仍由 `war_room_engine` 生成。

## Action audit 合同

`AgentActionDecision` 保留旧 `decision` 字段，并追加 V1.2 字段：

- `outcome`: `accepted | rejected | constrained | expired`
- `input_hash`: proposal 输入快照 hash
- `rule_version`: 当前一致性规则版本
- `rejection_reason`: 首个拒绝/约束原因
- `projection_status`: `not_projected | projected | constrained | blocked | expired`
- `projection_hash`: modifier 或未投影证明 hash

`agent_action_projection_audit.v1` artifact 为每个 proposal 保存最终 projection 状态、modifier 关联和最终结果 hash。它会在 checkpoint 恢复、hybrid replay 和 Replay Pack 生成时验证。

## 兼容策略

旧消费者继续读取 `decision=needs_revision/not_evaluated`；V1.2 使用 `outcome` 表达 canonical 状态，不改变现有 v1/v2 URL、War Room 字段、Run Diff 或 Replay Pack 的含义。

## 失败关闭

如果 projection audit 的 hash、计数、consistency hash 或 final result hash 不匹配，恢复和离线 replay 直接失败，不修复、不重新调用 Agent/LLM，也不写入新的确定性结果。
