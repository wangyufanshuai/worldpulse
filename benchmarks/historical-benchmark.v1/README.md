# historical-benchmark.v1 curation workspace

This directory contains only reviewed metadata and schemas. It intentionally does
not contain the 120 historical cases, official source files, or blind labels.

The release curator must produce:

1. an approved `source-plan.json` with 120 cases (20 per domain, 15 development
   and 5 blind);
2. an `acquisition-lock.json` generated by the explicit, reviewed URL fetch;
3. a manifest generated from the lock file; and
4. a sealed blind label pack generated outside the API/container.

Raw source bytes belong under `data/benchmarks/sha256/{prefix}/{sha256}` and must
never be committed to Git. `python -m app.manage benchmark verify` must report
120 cases and no missing or invalid blobs before the suite can be used for a
release batch.
